# TruthLayer

TruthLayer is governed execution and institutional intelligence infrastructure for high-stakes professional work. Tax Continuity OS is the first product built on the platform.

## Current state

The first production kernel is live at https://truthlayer-vision.albanysf.chatgpt.site/workspace and includes persistent evidence records, private file storage, source-linked assertions, conflict detection, reviewer decisions, obligations, audit history, continuity reporting, and governed project memory.

This repository is the external engineering control point for the broader product build. It begins with public-safe architecture, build standards, and automated validation. Proprietary product source and implementation details must not be mirrored here while the repository remains public.

## Product standard

TruthLayer is not a prototype, document archive, or chat wrapper. The target is a secure, multi-tenant production platform with native ingestion, entity resolution, evidence-weighted truth objects, obligation and reliance controls, durable agent orchestration, human approval gates, deliverable generation, observability, and enterprise operations.

## Build sequence

1. Production spine: identity, tenancy, durable jobs, native connectors, extraction, entity resolution, and observability.
2. Governed execution: Decision Files, reliance policies, work plans, approvals, deliverables, audit write-back, and revocation cascades.
3. Firm platform: configurable ontology, firm rules, permissions, administration, APIs, billing, and integration management.
4. Company-scale expansion: additional professional-service products on the same control plane.

## Repository policy

No credentials, customer data, regulated records, proprietary rule libraries, or production secrets may be committed. Convert this repository to private before mirroring the complete application source.
